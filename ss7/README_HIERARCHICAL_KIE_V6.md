# V6 short invariant pilot

Two parallel jobs; 15-minute job cap, Python timeout 11 minutes. Reused V5 group
156101 (development) and fresh group 176101. Same aggregate world, signed KIE,
five classes, no modifications to attack or benign mechanisms. 12 worlds/group,
20 test episodes/group. No independent confirmation claim for reused group.

Add aggregate message-pair residuals, dialogue and destination ratios, signed
normalized link residuals, multiscale past/current statistics. These are aggregate
consistency indicators only; the simulator cannot observe transaction-level
authorization or state, so no claim of protocol-state invariants. No new attack
mechanism, no actual operator validation. Zone RF trained on graph-only features
on independent fusion world, separate alert channel, no local decision veto.

Compare exact V4 expanded calibration on same data, V6 full hierarchy,
local-only and graph-only ablations. Primary budget 20 false window alerts/day,
three consecutive windows confirmation. Sensitivity 100/500. Train/validation
per-class AUROC/AP diagnostic for fixed RF complexity grid; training is
resubstitution and not an independent estimate. HGB compromise model fixed.
Select configuration on validation only; test used after selection. Full hierarchy
always includes graph channel; ablations not eligible for selection. Null test
mandatory, metadata not features. No claims of new protocol-level observation
or unknown-attack capability. Full confirmation requires larger unseen worlds.
