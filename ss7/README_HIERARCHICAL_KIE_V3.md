# SS7 KIE V3

Addresses V2 score saturation and suppression of the more effective local compromise
detector. Uses the same isolated aggregate simulation, adaptive compromise and
serialized signed KIE delivery. Four external classes remain traffic-effect proxies,
not evidence of malicious intent or real protocol exploits. New observable
features describe external OD share/concentration and past-only changes.

L1: RF service and HGB compromise specialists. L2: RF corroboration trained on
independent fusion worlds, using graph/zone evidence and local scores. L3: robust
unbounded role-specific normalization, causal temporal evidence, independent
channel thresholds and union of decisions. No graph veto. Fixed validation window
alert budget allocated 50/40/10 percent to service/compromise/corroboration.
The union does not exceed the sum of branch budgets on validation. Test can exceed
budget due to distribution shift. Primary budget 20; 100,500,1000 are diagnostic
operating points, not alternative success criteria. Three consecutive positive
windows confirm a local episode. The budget counts windows, not incidents.

Each replication: 5 local train, 3 fusion, 2 reference, 3 validation, 3 test worlds
with distinct seeds; 0.35 days per world, 3 episodes/class. Three replications.
All feature arrays are generated before labels are joined; graph aggregation is
grouped by world. Paired zero-effect test mandatory. Flat RF/hard cascade and
individual channels evaluated on same test worlds. Leave-one-attack-out diagnostic
trains a binary RF without the held-out class; its threshold uses benign validation.
Novelty-only model trained on benign data. Neither establishes unknown real attack
detection. Missing/invalid KIE is not affirmative traffic evidence.

Archives metrics, budget sensitivity, predictions, KIE overhead, channel thresholds,
scenario manifests, leave-one-out metrics. No calibrated operator data; transport
calibration disabled by default; KIE channel remains synthetic. V1/V2 unchanged.
