# Обновлённый интерфейс редактора топологий

Запуск (как и раньше):

```bash
python -m gui
```

Новых зависимостей у редактора нет — используется стандартный Python Tkinter.

## Что изменилось

- Двухуровневая панель управления: открытие, сохранение и запуск симуляции доступны сразу.
- Режимы редактирования находятся в одной группе, а тип узла и параметры отображения — отдельно.
- Масштабирование кнопками «−» и «+», по колесу мыши, а также «Вписать» для всей схемы.
- Сводка сети внизу холста: узлы, связи, MASTER и компоненты связности.
- Панель инспектора можно расширять и сужать, перетаскивая разделитель.
- Длинные формы свойств узлов и связей прокручиваются.
- Обновлены светлая и тёмная палитры; для новых профилей включена тёмная тема. Сохранённая пользователем тема не сбрасывается.
- Shift + перетаскивание левой кнопкой мыши перемещает полотно.

## Горячие клавиши

| Действие | Клавиша |
| --- | --- |
| Выбор / Узел / Связь / Удаление | Alt+1 / Alt+2 / Alt+3 / Alt+4 |
| Отмена текущего режима / действия | Esc |
| Создать / Открыть / Сохранить | Ctrl+N / Ctrl+O / Ctrl+S |
| Переключить панель инструментов | F8 |
| Показать / скрыть инспектор | F9 |
| Полный экран / презентация | F11 / F12 |
| Настройки вида | Ctrl+, |

Кнопка **Горячие клавиши** в верхней панели показывает справку прямо в приложении.

## Проверка

```bash
python -m compileall -q gui tests/test_gui_studio.py
python -m unittest tests.test_gui_studio -v
```

На Linux GUI smoke-тест можно запускать с виртуальным дисплеем:

```bash
xvfb-run -a python -m unittest tests.test_gui_studio -v
```

Существующие сценарии и формат JSON-топологий не менялись.
