# Независимые испытания S10 на Open5GS

Три отдельные регистрации по 3600 окон для 32 функций. На целевой функции slot-4 зарегистрировано девять тридцатиоконных эпизодов. Веса и пороги зафиксированы до сбора. Первое обнаружение во всех девяти эпизодах пришлось на начальное окно.

Обнаружено 250 из 270 поражённых окон (92,59 %). Число ложных тревог по прогонам — 89, 48 и 67 на 115 110 нормальных окон в каждом. Всего 204/345 330 (0,0591 %), на контролируемой функции отдельно 5/10 530 (0,0475 %). Доля подтверждённых среди всех тревог — 250/454 (55,07 %). Дополнительное объединение с независимым контролем сохранило решения зафиксированного детектора.

Третий вариант использует изолированный пустой каталог с измеренными локальными запросами. В архивном опыте 91401 запрос обрабатывал реестр Open5GS. Прогоны 91411–91413 относятся только к S10 и нормальному фону. Проверены контрольные суммы отдельных записей, соответствие фактических изменений запланированным и совпадение потоковой и пакетной обработки.
